# Ayesha Nadeem | Portfolio Website (React)

Full Stack (MERN) web developer, Lahore. Built with React + Vite.

## Demo projects
Demo projects, built with AI's help, then understood and modified by me.

- Restaurant Landing Page (Chulha House, fictional): `public/demos/restaurant/index.html`
- Online Store UI (Noor & Co., fictional): `public/demos/store/index.html`
- Small Business Website (CoolCare, fictional): `public/demos/business/index.html`

## Edit your content
Open `src/data.js` to change contact links, prices, story, projects and testimonials.

## Run locally
```
npm install
npm run dev
```

## Deploy
Hosted on Vercel from this GitHub repo (Framework: Vite, Build: `npm run build`, Output: `dist`).
